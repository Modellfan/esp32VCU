## Checkbox Reference Notes

- Checkbox controls are small square UI marks, not desktop-style buttons.
- The unchecked state is a thin white square outline on black.
- The checked state keeps the white square outline and adds a cyan inner fill separated from the border by a small inset.
- No radio-button circles are used for binary checkbox states.
