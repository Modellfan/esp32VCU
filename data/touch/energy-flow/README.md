# Energy Flow Assets

This folder contains the image assets and vector layout metadata for the page-5 energy-flow view.

Expected image files:

- `img/vehicle-top-xray.png`
- `img/hv-battery-pack.png`
- `img/drive-unit-crop.png`
- `img/inverter-controller.png`
- `img/charger-dcdc-module.png`
- `img/charge-port.png`
- `img/service-disconnect.png`
- `img/front-hv-junction-box.png`
- `img/rear-hv-junction-box.png`

Layout metadata:

- `energy-flow-layout.json`

The JSON uses a 1024 x 600 coordinate system. Each image entry defines `x`, `y`, `width`, `height`, `rotation`, `opacity`, `zIndex`, and `fit`. Flow vectors are stored separately under `vectors`.
